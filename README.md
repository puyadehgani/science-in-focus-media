# Science in Focus — media

Public media repository for the *Science in Focus* social video series by Dr. Puya Dehgani-Mobaraki (ENT, rhinology).

- Videos are published as **GitHub Release assets** (one release per episode) so that social platforms can fetch them by URL.
- Each episode folder holds `manifest.json` (titles, captions, checks) — the publishing queue itself lives in Make.
- Personal scientific content. Not institutional communication from Azienda USL Umbria 1; the information and opinions expressed do not represent its views. This content does not replace a medical assessment.
